# Currency Converter

A web application that converts amounts between different currencies using exchange rates fetched from an external API.

## Features

- Convert between multiple currencies
- Fetch exchange rates using an API
- Select source and target currencies
- Display country flags for selected currencies
- Interactive user interface

## Technologies Used

- HTML
- CSS
- JavaScript
- Frankfurter API

## What I Learned

- DOM manipulation using `querySelector()` and dynamic attribute updates.
- Event handling using `addEventListener()`.
- API integration and working with JSON responses.
- Asynchronous JavaScript using Promises and `async/await`.
- Retrieving user input and selected values using `.value`.
- Dynamically updating currency selections, country flags, and conversion results.
- Debugging JavaScript errors related to variable scope, DOM selectors, API URLs, and asynchronous code.

## Challenges Faced

- Constructing API URLs using dynamically selected currencies.
- Selecting and accessing HTML elements correctly through JavaScript.
- Extracting exchange rates from API responses.
- Understanding asynchronous requests and the use of `await`.
- Updating image sources and HTML attributes dynamically.
- Identifying and fixing JavaScript errors through debugging.
